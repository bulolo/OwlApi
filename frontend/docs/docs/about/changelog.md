# 更新日志

OwlApi 持续快速迭代。在这里，你可以了解每个版本的核心改动与新功能。

## v0.1.9 · 2026-05-17 📜 版本历史与发布流重构

### 🏗️ 数据模型重写
- 拆分原 `endpoint_releases` 单表：`endpoint_versions`（不可变历史快照）+ `endpoint_active_version`（线上指针，主键约束保证至多一个 active）+ `endpoint_activation_log`（审计流水）
- `api_endpoints` 回归「草稿/工作区」单一语义，去除冗余 `status` / `published_release_id` 字段，新增 `updated_at` 派生 `has_draft`
- 版本快照内联存储脚本和数据源引用，避免历史版本因脚本被改而行为漂移

### 🚀 发布流程精细化
- 顶栏拆分按钮：「发布上线」一键发布（创建版本 + 激活）；下拉提供「仅创建版本（不上线）」用于审批/灰度场景
- 新增「还原到线上 vN」：丢弃所有未发布修改，原子地回到当前线上版本
- 发布、创建版本均要求填写发布说明（Note），用于变更追溯
- 删除版本：3 道护栏（active / 唯一版本不可删，操作流水永久留痕）
- 上线中接口必须先下线才能删除（前后端双重守卫）

### 📜 版本历史 Tab 全新设计
- 视图切换：版本列表 / 操作流水（Timeline）
- 顶部状态摘要：「线上 v3 · 最新 v4 待上线 · 共 7 个版本」一行可见
- 版本行：发布说明预览、创建人、待上线徽章、复制到编辑器、删除
- **版本对比 diff**：标量字段 before/after、参数增删改高亮、SQL 行级 diff（基于 jsdiff 库）
- 「复制到编辑器」流程新增橙色提示横幅，明确"基于 v3 编辑"上下文，避免修改混淆

### 📋 调用日志 Tab
- 新增接口级访问日志（access log），记录每次外部调用的方法、路径、参数、状态码、耗时、错误、IP、UA、版本号
- 状态码段筛选（成功 / 客户端错误 / 服务端错误）、关键词搜索、自动刷新（30s）
- 行展开查看完整入参 JSON 与错误堆栈
- 异步 fire-and-forget 写入，不影响主请求性能

### 🎨 UX 收敛
- 5 色状态徽章：未发布 / 草稿 / v3 已上线 / 有未发布修改 / v4 待上线 / 已下线
- 脚本由可编辑下拉改为**只读小标签** + 点击弹窗预览代码，编辑统一收敛到 SQL 设计器
- 移除迷惑的「保存草稿」顶栏按钮（实际场景几乎用不到），唯一手动保存入口收敛到「复制历史版本到编辑器」后的横幅
- SQL 设计器关闭前若有未保存修改弹确认，避免误丢
- 操作流水正确显示 SuperAdmin（之前因 tenant_users 过滤被误显示为"用户#1"）

### 🔧 其他修复与清理
- 修复缓存失效 key 类型不一致导致状态徽章不刷新的 bug（projectId 的 string/number 混用）
- 修复列表查询因 JOIN 列名歧义导致接口返回 500 的 bug
- `endpoint_activation_log` 冗余记录版本号，版本被删后流水仍能正确显示 vN
- `cmd/init/main.go`：seed 时 `publisherID` 改用真实用户 ID，`maxVersions` 用租户配置
- `SuperAdmin` 不再写入 `tenant_users`（中间件已自动豁免）
- Schema 一致性：所有时间戳字段统一 `NOT NULL`；补 `api_groups` / `scripts` 缺失索引
- 删除孤儿文件 `SettingsTab`、`LogsPlaceholder`

## v0.1.7 · 2026-05-13 🗄️ 多数据库全面接入

### 🔌 六类数据源支持
- 新增 MySQL、PostgreSQL、SQL Server、SQLite、StarRocks、Apache Doris 全面接入，驱动均已集成，开箱即用
- DSN 自动推断：优先使用 `db_type` 字段确定驱动，兜底使用 DSN 前缀识别，无需手动配置驱动类型

### 🖥️ 数据浏览器
- 新增表结构浏览（Schema 查看）功能，可视化展示远端数据库所有表与字段定义，无需额外工具
- 新增表数据预览，支持指定行数限制（最多 500 行）快速抽样查看

### 📋 结构化连接表单
- 数据源配置告别手写 DSN，改为可视化字段填写（主机、端口、用户名、密码、数据库名）
- 支持「测试连接」按钮，创建前实时验证连通性并返回延迟（ms）

### 🔧 其他改进
- 修复生产部署后网关/数据源无初始数据的问题
- 修复 `tenant` 列表 `ORDER BY` 导致超管登录默认租户错误的问题
- 修复登录成功后偶发卡在登录页的问题

## v0.1.6 · 2026-04-01 🌐 网关执行器演进

### 🛡️ 混合云架构
- 发布全新架构大版本：Gateway 可直接部署在深层内网，主动向控制面建立 gRPC 反向隧道
- 彻底告别公网 IP 和复杂的白名单配置，数据库防火墙端口无需对外开放
- 新增内置 Gateway：`docker-compose.yml` 自动包含本地网关节点，开箱即用

### ⚙️ 多租户 RBAC
- 上线 RBAC 体系（SuperAdmin / Admin / Viewer），实现多数据源、多项目的严格权限隔离
- SuperAdmin 可跨租户管理，Admin 管理租户内全部资源，Viewer 只读访问

### 📦 参数推断重构
- 支持在 SQL 编写时动态识别 `:变量`，一键映射并暴露为标准的 HTTP Query 参数或 Body
- 参数类型自动推断，支持手动配置 `required`、`default`、`desc` 等属性

### 📜 JS 脚本引擎
- 新增前置脚本（pre_script）和后置脚本（post_script）支持
- 基于 Goja 引擎执行，可在 SQL 执行前修改参数，在 SQL 执行后转换响应数据
- 支持独立脚本管理，可在多个接口间复用

### 🌐 版本管理与发布流
- 接口支持草稿（draft）→ 发布（published）工作流
- 发布时创建快照（Release），已发布接口调用快照执行，编辑草稿不影响线上
- 支持版本回滚和接口下线，租户可配置最大保留版本数

### 📚 官网全线升级
- [owlapi.cn](https://owlapi.cn) 官网焕新，全面适配企业级 UI 体验
